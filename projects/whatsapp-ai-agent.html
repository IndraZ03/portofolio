FEATURE 01 / MESSAGING

WhatsApp-Native Interface

Interaksi melalui kanal WhatsApp, dengan Baileys sebagai konektor pesan. Fokusnya akses percakapan tanpa antarmuka aplikasi terpisah.

  • Baileys menangani koneksi WhatsApp Web.
  • Kemampuan grup, mention, suara, dan media tidak diasumsikan dari library.
FEATURE 02 / ORCHESTRATION

Hermes Agent Core

Hermes Agent menempati pusat koordinasi percakapan. Pemisahan peran ini membuat koneksi pesan tidak disamakan dengan logika agent.

  • Hermes Agent merupakan runtime agent yang dikonfirmasi pemilik proyek.
  • Tools spesifik dan persistent memory memerlukan verifikasi terpisah.
FEATURE 03 / VECTOR KNOWLEDGE

Knowledge Retrieval with Qdrant

Qdrant menyediakan basis pengetahuan berbentuk vektor. Pencarian konteks dipisahkan dari transport pesan dan akses model.

  • Peran yang dikonfirmasi: vector knowledge database.
  • Model embedding, schema koleksi, ingestion otomatis, dan sitasi belum diklaim.
FEATURE 04 / MODEL ACCESS

Model Connectivity via 9router

9router berperan pada akses model AI. Agent dan model tetap dua komponen berbeda; 9router bukan model yang menghasilkan jawaban.

  • Lapisan akses model dibedakan dari Hermes Agent.
  • Tidak menyiratkan provider tertentu, failover, atau routing berbasis biaya.

Overview

Conceptual integration
Pilih komponen untuk membaca peran dan batas integrasi.

Architectural boundaries

01 / TRANSPORT ≠ AGENT

Koneksi bukan orkestrasi

Baileys menghubungkan WhatsApp, Hermes mengoordinasikan agent. Tidak menambahkan bridge atau gateway kedua tanpa bukti.

02 / KNOWLEDGE ≠ CHAT HISTORY

Retrieval sesuai kebutuhan

Qdrant menjelaskan knowledge berbentuk vektor, bukan klaim bahwa semua pesan disimpan atau selalu dicari ulang.

03 / ROUTER ≠ MODEL

Akses terpisah dari inferensi

9router berada pada akses model. Kemampuan failover, pemilihan provider, dan token accounting tidak dinyatakan tanpa konfigurasi pendukung.

Tech Stack · Confirmed by owner

Teknologi di balik percakapan.

Empat komponen yang telah dikonfirmasi. Tidak ada tambahan runtime, framework, model, atau infrastruktur berdasarkan tebakan stack umum.

01 / MESSAGING

Baileys

Library koneksi WhatsApp Web untuk jalur pesan agent.

How it’s used

Menyediakan konektivitas WhatsApp pada proyek. Versi, mode autentikasi, serta kemampuan grup dan media tidak ditetapkan dari dokumentasi yang tersedia. Bukan WhatsApp Business Cloud API resmi.

02 / AGENT RUNTIME

Hermes Agent

Inti agent untuk mengoordinasikan percakapan dan respons.

How it’s used

Dipisahkan secara konseptual dari transport pesan, model access, dan vector store. Daftar tools, skills, serta mekanisme memory aktif memerlukan audit source agent.

03 / MODEL ACCESS

9router

Perantara akses model AI pada proyek ini.

How it’s used

Nama mengikuti komponen yang dikonfirmasi pemilik. Tidak disamakan otomatis dengan layanan lain dan tidak menyiratkan kebijakan routing atau failover tertentu.

04 / VECTOR KNOWLEDGE

Qdrant

Database vektor untuk knowledge, dengan pencarian konteks sebagai peran konseptual.

How it’s used

Knowledge dibedakan dari riwayat chat. Embedding model, collection schema, metadata filtering, dan indexer tidak dinyatakan sebagai implementasi terverifikasi.
