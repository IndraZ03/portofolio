Monitoring AWOS & AWS

Pengembangan dashboard adaptif untuk menampilkan AWOS di wilayah Kalimantan Timur dan Kalimantan Selatan serta AWS di Kalimantan Timur untuk teknisi dan Airnav.

Dashboard Adaptif

AirNav meminta adanya layanan display AWOS di wilayah Kalimantan Timur dan Kalimantan Selatan. Dari permintaan tersebut, dikembangkan dashboard adaptif yang dapat menampilkan data AWOS di wilayah Kalimantan Timur dan Kalimantan Selatan.

Monitoring Teknisi

Dashboard juga menampilkan AWS di wilayah Kalimantan Timur agar teknisi dapat memonitor AWS dan AWOS sekaligus sesuai kebutuhan AirNav.
